# HKKS (Hollow Knight Key Sync)

开源的《空洞骑士》多窗口键盘同步工具：让多个后台游戏窗口各自接收独立键位，
配合本地双人 Mod 实现无手柄同屏双人。仅用于离线单机场景。

## 目录结构

- `KeySync/`：C# 主程序（窗口查找、键位路由、注入器、预设布局）
- `HookDLL/`：C++ 注入 dll（IAT Hook，让游戏以为自己在前台）

两者关系：KeySync 运行时会从自己 exe 同目录读取 `HookDLL.dll` 并注入游戏进程，
**编译后必须把两个产物放在同一文件夹**。

## 编译

### HookDLL（C++）
1. Visual Studio 安装"使用 C++ 的桌面开发"工作负载。
2. 打开 `HookDLL/HookDLL.vcxproj`。
3. 平台选 **x64**，配置 Release，生成 → 得到 `HookDLL.dll`。

### KeySync（C#）
1. 打开 `KeySync/KeySync.csproj`。
2. 平台选 **x64**，生成 → 得到 exe。

### 组装
把 `HookDLL.dll` 复制到 KeySync 的 exe 同目录。

## 使用

1. 以管理员身份运行 KeySync。
2. 打开游戏窗口 → 点"刷新窗口"。
3. 给窗口 2/3/4 录键（各窗口键位不可重复，Esc 公共）。
4. 可选：选预设自动无边框布局；点"注入后台Hook"提升后台稳定性。
